# Glossary - 3D Print Management System

## 3D Printing Technology Terms

### Materials
- **Filament**: Thermoplastic material (PLA, ABS, PETG) fed into FDM/FFF printers
- **Resin**: Liquid photopolymer cured by UV light in SLA printers
- **Support Material**: Temporary structures to support overhangs during printing
- **Build Plate**: Platform where prints are built, may require adhesion aids

### File Formats
- **STL**: Standard Tessellation Language, most common 3D model format
- **OBJ**: Wavefront OBJ format, includes color/texture information
- **3MF**: 3D Manufacturing Format, Microsoft's modern alternative to STL
- **G-code**: Machine instructions generated by slicer software
- **FORM**: Formlabs proprietary format for SLA printers

### Printing Process
- **Slicing**: Converting 3D model into printer instructions (G-code)
- **Layer Height**: Thickness of each printed layer (affects quality/speed)
- **Infill**: Internal structure density (affects strength/material usage)
- **Print Speed**: How fast the print head moves (affects quality/time)
- **Bed Leveling**: Ensuring print surface is properly calibrated

## System Architecture Terms

### Components
- **Flask API**: Backend web service handling all business logic
- **Next.js Frontend**: React-based user interface for students and staff
- **PostgreSQL**: Relational database storing job and event data
- **RQ (Redis Queue)**: Background task processor for emails and thumbnails
- **Docker Compose**: Container orchestration for development/deployment

### Authentication
- **Workstation Login**: Computer-based authentication with shared passwords
- **Staff Attribution**: Required name selection for all state-changing actions
- **JWT Token**: JSON Web Token for workstation session management
- **Session Duration**: How long workstation login remains valid (12 hours)

### File Management
- **Network Storage**: Shared storage accessible from all workstations
- **Authoritative File**: Current "correct" version of job file (original or sliced)
- **metadata.json**: Job details stored alongside files for data resilience
- **File Protocol**: Custom 3dprint:// protocol for opening files in slicer software

## Business Process Terms

### Job Lifecycle
- **Submission**: Student uploading file through web form
- **Review**: Staff evaluating submission for approval/rejection
- **Approval**: Staff setting print parameters and authorizing job
- **Confirmation**: Student authorizing final cost via email link
- **Production**: Physical printing process
- **Fulfillment**: Payment processing and pickup
- **Archival**: Long-term storage of completed jobs

### Roles
- **Student**: Person submitting 3D models for printing
- **Staff**: Lab personnel managing print queue and operations
- **Administrator**: Staff member with elevated system management privileges
- **Workstation User**: Anyone logged into a shared computer terminal

### Workflow States
- **UPLOADED**: New submission awaiting staff review
- **PENDING**: Approved job awaiting student confirmation
- **READYTOPRINT**: Confirmed job ready for printing
- **PRINTING**: Job currently being printed
- **COMPLETED**: Finished print awaiting pickup
- **PAIDPICKEDUP**: Student collected and paid for print
- **REJECTED**: Staff declined submission
- **ARCHIVED**: Old job in long-term storage

## Technical Implementation Terms

### API Design
- **RESTful**: HTTP-based API following REST architectural principles
- **CORS**: Cross-Origin Resource Sharing for frontend-backend communication
- **Rate Limiting**: Preventing abuse by limiting request frequency
- **JSON Response**: Standard data format for API responses
- **Status Codes**: HTTP codes indicating request success/failure

### Database
- **ORM**: Object-Relational Mapping (SQLAlchemy) for database operations
- **Migration**: Database schema change management
- **Event Log**: Immutable audit trail of all system actions
- **Foreign Key**: Database relationship linking records
- **Transaction**: Atomic database operation ensuring data consistency

### Frontend
- **App Router**: Next.js 13+ file-based routing system
- **shadcn/ui**: Component library built on Radix UI primitives
- **Tailwind CSS**: Utility-first CSS framework
- **TypeScript**: Strongly-typed JavaScript for better development experience
- **Client/Server Components**: Next.js rendering strategies

### File Operations
- **Copy-Update-Delete**: Resilient file movement pattern
- **Path Validation**: Security check ensuring files are in authorized locations
- **File Locking**: Preventing concurrent modifications
- **Atomic Operations**: File changes that complete fully or not at all
- **Integrity Check**: Verification that database and files are synchronized

## Domain-Specific Abbreviations

- **FDM/FFF**: Fused Deposition Modeling / Fused Filament Fabrication
- **SLA**: Stereolithography (resin printing technology)
- **PLA**: Polylactic Acid (common filament material)
- **ABS**: Acrylonitrile Butadiene Styrene (durable filament material)
- **PETG**: Polyethylene Terephthalate Glycol (chemical-resistant filament)
- **STL**: Standard Tessellation Language (not "StereoLithography")
- **CAD**: Computer-Aided Design
- **CNC**: Computer Numerical Control

## Status Display Conventions

### Internal Code (API/Database)
- UPPERCASE format: `UPLOADED`, `PENDING`, `READYTOPRINT`

### Directory Names (File System)
- PascalCase format: `Uploaded/`, `Pending/`, `ReadyToPrint/`

### User Interface (Dashboard)
- Title Case with spaces: "Uploaded", "Ready to Print", "Paid & Picked Up"

## Common Error Terms

- **Orphaned File**: File exists in storage but has no database record
- **Broken Link**: Database record points to non-existent file
- **Stale File**: File in wrong directory for job's current status
- **Lock Timeout**: Exclusive job lock expired due to inactivity
- **Token Expired**: Student confirmation link no longer valid
- **Rate Limited**: Request blocked due to too many attempts
